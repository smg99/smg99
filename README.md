## What I care about

**Frontend Architecture** · **Design Engineering** · **Motion & Interaction** · **TypeScript** · **React / Vue / Nuxt** · **Design Systems** · **Performance** · **AI-assisted delivery**

### Bias

- **UX is product behavior** — motion, feedback, and clarity are not decoration.
- **Small before large** — prove the interface before building the cathedral.
- **Useful before impressive** — fancy is welcome; useless is not.
- **Public by default** — share the work clients can actually click.
